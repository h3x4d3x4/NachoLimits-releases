# Nacho Limits releases

Nacho Limits shows your AI plan limits (Claude, Codex, Gemini) in the MacBook notch. This public repo hosts the signed, notarized DMGs (as release assets) and `appcast.xml`, the Sparkle feed the app reads to update itself. Needs macOS 15 or later.

Install: download [NachoLimits.dmg](https://github.com/h3x4d3x4/NachoLimits-releases/releases/latest/download/NachoLimits.dmg), open it and drag Nacho Limits to Applications.
